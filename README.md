# Land Vista

Land Vista is a real estate website for browsing homes, flats, and shops. Visitors can search by city, property type, size, and budget, open a listing for photos and details, and send an inquiry to the office.

## Features

- **Home** shows a photo carousel, a search form, property categories, and the latest listings.
- **Listings** collects every property in one place, with beds, baths, area, and location.
- **Property pages** show the gallery, price, owner, phone number, room details, amenities, description, and a map.
- **Search** filters results by what the visitor entered on the home page.
- **About** explains why to choose Land Vista, the three steps from search to move-in, and client reviews.
- **Contact** includes a message form plus the office phone, email, hours, and address.
- **Login and register** provide account screens for returning and new visitors.

## Pages

| Path | Page |
| --- | --- |
| `/` and `/home` | Home |
| `/listings` | All listings |
| `/view_property` through `/view_property5` | Individual properties |
| `/search` | Search results |
| `/about` | About |
| `/contact` | Contact |
| `/login` | Login |
| `/register` | Register |

## Tech

- React 18 and Create React App
- React Router for page navigation
- Tailwind CSS alongside the site stylesheet
- Mapbox GL for property maps
- Font Awesome for icons

## Run locally

```bash
npm install
npm start
```

The site opens at [http://localhost:3000](http://localhost:3000).

To create a production build:

```bash
npm run build
```
